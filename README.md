# FrontendCraft

Interactive bilingual learning platform for frontend fundamentals — HTML, CSS, JavaScript, and Tailwind.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Labs

- `/` — lab hub
- `/tracks` — browse all labs
- `/javascript` — JavaScript curriculum
- `/html` — HTML curriculum
- `/css` — coming soon
- `/tailwind` — coming soon

## Stack

Next.js (App Router), Tailwind CSS, Framer Motion, Lucide Icons.
