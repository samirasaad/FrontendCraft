# FrontendCraft

Interactive bilingual learning lab for frontend fundamentals — HTML, CSS, JavaScript, and Tailwind.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Tracks

- `/` — track hub
- `/javascript` — JavaScript curriculum
- `/html` — HTML curriculum
- `/css` — coming soon
- `/tailwind` — coming soon

## Stack

Next.js (App Router), Tailwind CSS, Framer Motion, Lucide Icons.
